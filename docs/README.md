# Sound Transportation 文档

面向门店部署、Control App 对接及后续维护。以仓库当前代码为准；源码检查不等于多台电脑的现场验证。

| 文档 | 用途 |
| --- | --- |
| [部署与配置](DEPLOYMENT.md) | 安装、保留配置、开机运行、接收端与发送端设置 |
| [Control App 接口](CONTROL_API.md) | HTTP 调用、通道识别、切换和静音 |
| [音频架构与限制](ARCHITECTURE.md) | 数据流、模块职责、当前实现边界 |
| [故障排查](TROUBLESHOOTING.md) | 日常问题的检查顺序 |
| [开发与待办](DEVELOPMENT.md) | 编译、发布、验证、未来功能 |

## 维护约定

- 配置或安装方式改变时，同步更新部署文档。
- API 参数或行为改变时，同步更新接口文档，并说明兼容性。
- 新功能先列入待办，完成实现和验证后再标记为可用。
- 发版记录使用 Git 提交历史和安装包中的 `VERSION.txt`；不要仅凭目录名判断正在运行的版本。
- 门店真实 IP、账号及配置备份不要直接提交到公开仓库。
