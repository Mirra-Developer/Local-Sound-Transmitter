# 开发、发布与待办

## 构建

Windows 环境，安装 .NET 8 SDK。统一程序目标为 `net8.0-windows`，使用 Windows Forms 托盘和 ASP.NET 管理 API。

```powershell
dotnet build .\SoundTransportation.sln
.\scripts\build-package.ps1 -Version 2026.09.09-example
```

第二条仅为版本名称示例，每次正式发布应使用新的唯一名称。脚本生成 Windows x64 自包含 ZIP，包含运行时、EXE、wwwroot、默认配置和安装脚本。产物位于 `release/`；源代码提交与安装包发布是不同步骤。

## 发布检查

- 验证构建成功和实际发布文件存在；编译通过不代表音频现场验证通过。
- 干净安装与覆盖升级均测试，确认旧配置保留。
- 新版 start 与 Windows 登录启动均无浏览器自动打开；托盘打开管理页、退出、重复启动检查。
- 使用至少两台电脑测试 UDP、IP 绑定、红色掉线指示和重新上线。
- Control App 测试远程选择、本地恢复、音量参数及连续切换。
- 配置保存后验证实际发送、接收与输出，而不是只检查成功提示。

## 待办状态

| 事项 | 状态 | 验收方向 |
| --- | --- | --- |
| 中文项目文档 | 已整理 | 配置、API、限制有独立入口 |
| 托盘运行 | 已实现，交互实测待补 | 右键菜单、退出、登录启动和单实例 |
| 总输出 Limiter | 讨论中，未实现 | 峰值限制、旁通、压低量显示；不能误称已覆盖本地 A |

| 本地采样路由 | 待修复 | 自动创建关闭时本地采样仍能更新本地通道 |
| 收发健康诊断 | 待实现 | 实际包计数、最后来源 IP、丢弃原因和服务错误 |
| 配置热重载可靠性 | 待完善 | 并发保存、设备异常、端口冲突时可恢复 |
| 音频会话恢复 | 待完善 | 多会话、进程重启、退出时恢复行为 |

音频保护需求尚未授权具体实现方案时，先维护设计和验收目标，不将讨论中的功能列入部署说明。
