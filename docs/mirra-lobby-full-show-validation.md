# Full Show 本机验证结果

2026-09-09，RTX 5090 Laptop GPU，24 个逻辑处理器。源码入口、启动/关闭命令和协议限制见 [完整流程契约](mirra-lobby-full-show-v1.md)。本报告对应未提交的隔离开发改动，不是现场部署验收。

## 完整流程

`show-accept-01` 用实际本地角色卡和约 40 秒教学文件，195.829 秒完成三轮，核对 9 次特效遮挡切点及完成事件，没有取消事件。每轮 EOS PTS 为 39960 ms，没有快进或用固定倒计时代替播放结束。最终返回第一阶段并开始开场才计为一轮完成。

| 实测节奏 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
|---|---:|---:|---:|
| 第三阶段显示确认 → 全屏转场请求 | 7.010 秒 | 7.018 秒 | 7.030 秒 |
| 全屏 NDI 转场完成 → 返回转场请求 | 10.271 秒 | 10.266 秒 | 10.201 秒 |

后者包含保持 10 秒后准备下一轮首帧、确认新 Lobby GPU 帧的约 0.2–0.27 秒。第三阶段为原动画完成后保留 VS 与持续呼吸/光效，不反复重播收框和撞击。

已检查 3840×2160 输出截图：开场、实际教学、框内特效、框内 NDI、第三阶段运动、全屏特效、全屏 NDI、返回特效。网页边框/扫描线、人物与透视保持在画面中。截图证明代表性帧，不能单独证明每帧流畅或任意透明回放素材无色差。

断源验证另行通过：目标离线时拒绝框内切入；框内/全屏 NDI 已切入后保留最后画面；重启同一地址的本机发送器后恢复；发送器离线时仍能经特效返回 Lobby。未向真实 OB 电脑或现场 MES 发送命令。

控制页开始/停止按钮已实际检查；停止后流程为 stopped，教学 playing=false；重新开始继续从第一阶段准备。旧 14180 对比页保留。

## 4K 输出与新画面帧率

`show-resources-01/clean-210s` 在所有服务同时运行、教学及两种 NDI 转场持续循环时采样。210 份 Windows 计数器样本；因读取和序列化开销，首末样本跨度 231.07 秒，原生测量窗口 234.86 秒，不能称为精确 210 秒。该窗口未截图、未构建、未做故障注入，覆盖至少三轮完整返回。

| 指标 | 结果 |
|---|---:|
| 原生输出缓冲 | 3840×2160 |
| 软件 Present 调用平均 | 60.003 次/秒 |
| Lobby 新 GPU 纹理平均 | 53.313 帧/秒 |
| 全窗口最长呈现间隔 | 22.494 ms |
| 呈现间隔 P95 | 17.941 ms |
| 调度器记录的漏槽 | 0 |
| GPU 导入复制平均 / P95 | 1.708 / 2.925 ms |
| 整个采样窗口来源健康 | live |

**不能把此结果写成“所有内容稳定 4K60 新画面”。** Present 包括复用网页最后一帧；本轮网页纹理约 53.3 fps。原教学文件为 25 fps，占位 NDI 与特效为 720p60 输入，再进入 4K 输出。下一项性能工作应提高网页来源产帧率，尤其是两个同步网页视图的成本。

分位数只保留首 7200 样本，最长呈现间隔为整个测量窗口累计。漏槽为内部调度指标，0 不等于实体屏幕没有掉帧。原生窗口客户区 1280×720；检测到显示器 2560×1600/240 Hz 和 2560×1440/约 60 Hz，本轮未验证实体 4K60 大屏扫描。

早期开发轮曾有约 500 ms 停顿并取消转场。已移除媒体拉帧期间持有共享锁的情况、把元数据解码移到顶点阶段、把 PNG 编码移到后台；随后干净测量未重现该停顿，不能据此断言所有早期停顿均有同一根因。故障注入及截图轮不参与上表。

## 同时运行时的资源归属

CPU 为整机 24 逻辑处理器归一化百分比。内存为平均私有驻留内存，MiB；Lobby 包括 Electron 主进程、Renderer、GPU/Utility 子进程及隔离 Vite/esbuild。

| 部分 | CPU 平均 / 采样峰值 | 平均私有驻留内存 | 最忙 GPU 引擎平均 / 采样峰值 |
|---|---:|---:|---:|
| Mirraflow 原生合成/解码 | 1.81% / 4.41% | 872.8 MiB | 7.51% / 8.02% |
| Lobby 及开发服务器 | 8.97% / 10.50% | 522.5 MiB | 45.51% / 58.22% |
| 两者合计 | 10.78% / 13.79% | 1395.3 MiB | 49.03% / 62.18% |
| 本机占位 NDI 发送器 | 1.99% / 2.84% | 39.5 MiB | 0% |
| 本机只读数据 fixture | 0% / 0%（采样分辨率） | 15.2 MiB | 0% |
| 全部上述服务 | 12.76% / 16.08% | 1450.0 MiB | 49.03% / 62.18% |

表中是同一并行运行窗口的进程归属，不是分别关闭其他软件后测得的单独运行结果。GPU 先按同一物理引擎汇总，再选最忙引擎，不能把不同引擎的百分比直接相加。Windows 专用显存进程记账平均：Mirraflow 346.3 MiB、Lobby 1871.5 MiB、合计 2217.9 MiB；共享纹理可能重复记账，不代表唯一物理显存分配。CPU/GPU 峰值为约 1 秒采样，不能覆盖所有短瞬态。其他应用、DWM 和采样工具不在软件分组总计内。

Mirraflow 常驻内存包含三条预解码特效，约 633 MiB；不是每次切换持续累计新增。Sound Transmitter 未启动，本轮不包含任何声音功能或声音服务负载。
